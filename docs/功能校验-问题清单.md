## 二、待修复问题（按严重程度）

### 🔴 P0 — 数据正确性错误

**P0-1 预警中心（alerts 区块）用错数据源**
- 位置：`apps/web/core.js` reportPage `#alerts` 区块
- 现象：`<tbody>${events.map(...)}` 用 `events`（= cards 特殊内容）而非 `alerts`（= 突变预警）
- 影响：预警中心展示的是全部「特殊内容」，不是「突变预警」
- 修复：改用 `alerts` 数据（字段 id/level/time_label/text/start_ms/time），适配表格列

### 🟡 P1 — 硬编码假数据残留（分析结果来源不实）

**P1-1 data 页数据查看器（rawObject）假数据**
- 位置：`system.js` 第 104 行 `rawObject()`
- 残留：`duration_s:1122`、`video_valid:0.972/audio_valid:0.991`、`missing_intervals rPPG`、`report version:1.0.0/created 09:38:42`
- 修复：用真实 `task.duration`/`coverage`/`versions`/`task.completed`

**P1-2 报告中心（reportsPage）版本/时间硬编码**
- 位置：`system.js` 第 76 行
- 残留：`当前版本 1.0.0 / 关联任务 0086`、`2026.10.21 / 09:38:42`、`v1.0.0`
- 修复：版本用 `versions`，时间用 `task.created/completed`，任务用 `task.id`

**P1-3 热力图点击详情（data-heatcell）假基线**
- 位置：`core.js` 第 104 行
- 残留：`names/base/sd/units` 硬编码（心率72bpm、眨眼17次、基频171Hz 等）
- 修复：用 `__boot.heatmap.markers`（name/code）+ `metrics[]` 的 mean 作基线

**P1-4 关键词点击定位硬编码时间戳**
- 位置：`core.js` 第 104 行 `data-keyword` 分支
- 残留：`ts={压力:75,时间:730,...}`
- 修复：从真实 `segments`/`cards[].keywords` 出现时间定位

**P1-5 扩展指标贡献特征名硬编码（仅 fallback）**
- 位置：`core.js` 第 65 行 `renderMetric()` else 分支
- 残留：`currentMetric===5` 时 `[['瞳孔直径','停顿比例','语速'],...]`
- 修复：从 `extended`/`context` subs[].evidence 取真实特征名，无则「暂无证据」

**P1-6 语义页关键词词云硬编码**
- 位置：`core.js` reportPage `#semantic` 区块 `keywordrow`
- 残留：`[['压力',3],['时间',2],['睡眠',1],['能力',1],['调整',2],['未来',1]]`
- 修复：从真实 `segments`/`cards[].keywords` 统计关键词频率

**P1-7 语义页时间轴刻度硬编码**
- 位置：`core.js` reportPage `#semantic` 区块 `axistimes`
- 残留：`00:00 / 04:40 / 09:21 / 14:01 / 18:42`
- 修复：按真实 `duration` 均分生成

**P1-8 标志物页采样时间/定位硬编码**
- 位置：`core.js` 第 63 行 `renderMarker()`
- 残留：`采样时间 12:10`、`data-seek="730"`、`12:10 回看`
- 修复：用真实任务时间（如首个卡片时间）

**P1-9 「待复核 2 项」硬编码**
- 位置：`core.js` reportPage `reportmeta` + `taskCard`
- 残留：`待复核 <span class="reviewcount">2</span>`
- 修复：用真实未复核数（本版不落库，默认 0）
