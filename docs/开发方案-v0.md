## 2. v1 要做成什么

一个人、一台电脑、一段已有视频，在浏览器里完成一次心理画像：

1. 导入视频，调用数据基座抽出面部、头部、注视、声学、转写、行为事件、OpenFace AU。
2. 用 DeepSeek 把转写切成主题段。
3. 标志物重采样到 100 毫秒网格，算本人基线，再算每个主题段相对基线的 Z 分数。
4. 用预设公式打出六类参考指数。基座没有的生理量留空，不参与加权，不填 0。
5. 用预设突变规则标出异常点，和关键词、主题段交叉。
6. 每个特殊内容点做三层对比，把结构化结果交给 DeepSeek，生成现象、对比、趋势、预测四段文字。
7. 网页展示总览、热力图、预警清单、特殊内容卡片（可跳到视频时间点）、原始指标与复现信息。

v1 明确不做：现场摄像头采集、rPPG / 心率 / HRV / 呼吸、真实瞳孔直径、本地大模型、Electron、账号与计费、PDF、多人脸追踪。

## 3. 和数据基座的分工

基座继续只做客观特征，不改它的报告口径，不把诊断用语写进基座 HTML。

鸿心影鉴是新仓库里的上层：

```
视频文件
  → 子进程调用基座 pipeline（读 job 目录，不复制算法）
  → 画像层（本仓库）
       对齐 / 主题 / Z 分数 / 预设指标 / 突变 / 三层对比
  → DeepSeek（只收文本和汇总数字）
  → 网页
```

调用方式：使用基座虚拟环境执行 `python -m pipeline.cli`，输出到鸿心影鉴自己的 `data/jobs/<id>/features/`。基座目录通过环境变量 `FEATURE_BASE` 指向，默认 `/Users/ashaw/Documents/数据基座项目`。

AU 仍依赖基座现有的 OpenFace Docker。没有 Docker 时 AU 子项为 `not_available`，其余流程照常出报告。

## 4. 系统结构

```
鸿心影鉴/
  apps/web/                 Vite + React + ECharts
  apps/api/                 FastAPI
  packages/portrait/        对齐、指标、突变、对比（纯函数，可单测）
  config/
    indicators-0.1.0.yaml   子指标、权重、缺失策略
    rules-0.1.0.yaml        窗长、σ 阈值、持续时长、关键词表
    topics-0.1.0.yaml       主题标签
  data/jobs/<id>/
    source.mp4
    features/               基座原样产物
    portrait/               网格、主题、分数、卡片
    report.json
  .env                      DEEPSEEK_API_KEY，不进仓库
```

存储：SQLite 存任务状态，文件目录存视频和产物。任务状态：`queued → extracting → aligning → scoring → narrating → done | failed`。

网页只连本机 API（`127.0.0.1`）。无登录。

## 5. 分期

按这个顺序做。前一阶段验收通过再进下一阶段。

### P0 骨架

- 上传 mp4/mov，创建任务，子进程跑基座。
- 网页能看任务进度、基座原始指标表、转写文本、视频播放。
- DeepSeek 连通性检查（一次最小请求），密钥放 `.env`。
- 失败时展示基座 `run_log` 里的原因。

验收：一段样例视频能在网页里播，并看到基座指标，不经过大模型。

### P1 对齐与主题

- 把视觉帧、声学帧、AU 帧按各自时间戳落入 100 毫秒桶，桶内取均值，没有样本则空。
- 全片基线：各标志物的均值和标准差。有效时长不足 30 秒的标志物标记 `insufficient_baseline`，不算 Z 分数。
- 转写按语句送给 DeepSeek，归入预设主题。相邻同主题语句合并成主题段。
- 主题段 Z 分数矩阵。网页热力图：横轴主题段，纵轴标志物，颜色是 Z 分数。

验收：热力图上的任一格能点开，看到主题段原文、起止时间、该标志物的段均值和全片均值。

### P2 参考指数与突变

- 按第 6 节公式计算六类指数，写入 `indicators-0.1.0`。
- 按第 7 节规则扫描突变，和主题段、关键词交叉。
- 网页：雷达图（缺项扇区灰色）、指数拆解（子项、所用标志物、贡献前三）、预警清单。

验收：改 YAML 里的阈值或权重后重跑同一视频，分数和预警变化，且报告里写明配置版本。

### P3 特殊内容与叙述

- 触发：关键词命中，或突变，或两者同时（同时命中权重最高）。
- 三层对比：相对本人全片基线；该主题在全部主题中的排名；同一关键词多次出现时的标志物变化。
- 把对比 JSON 交给 DeepSeek，生成四段文字和预警等级。模型只能复述 JSON 里已有的数字。
- 卡片：触发类型、时间段、视频跳转、相关曲线、三层对比、四段文字、等级。

验收：卡片中的数字都能在 `portrait/` 里找到来源；关掉 DeepSeek 时卡片仍在，叙述区显示「未生成」。

### P4 导出

- 下载 `report.json` 和指标 CSV。
- 网页打印暂代 PDF。

## 6. 参考指数（预设 v0.1.0）

原则：

- 只使用基座已经输出的标志物。
- 子项先变成相对本人基线的 Z 分数，再截断到合理区间，映射成 0–100 的参考分。
- 一类指数 = 可用子项的等权平均。权重要写在 YAML 里，默认相等。
- 缺失子项不补 0，覆盖率一并展示，例如「4/6 子项」。
- 界面名称用「参考指数」。固定声明：描述本次录像中的行为偏离，不构成诊断、测谎或风险裁决。

v1 子项与数据来源：

| 类 | 子项 | 来源 | v1 |
|----|------|------|----|
| 心理健康 | 表情平坦度 | AU 活跃度偏低、波动小 | 做 |
| 心理健康 | 微表情频次 | 短时 AU 脉冲计数 | 做，并标注帧率置信 |
| 心理健康 | AU 活跃度 | 主要 AU 的均值 | 做 |
| 心理健康 | 面部血流灌注 | rPPG | 空 |
| 心理健康 | 语调平坦度、语速、停顿比例 | F0 标准差、语速、非语音占比 | 做 |
| 心理健康 | 声学抖动、共振峰 | 基座无抖动/共振峰专项 | 空 |
| 心理健康 | 心率、HRV、呼吸、rPPG 质量 | 无 | 空 |
| 情绪 | 稳定指数 | AU 极性代理序列的方差与一阶差分 | 做。极性用 AU12 相对 AU4/AU15，名称写明是面部动作代理 |
| 情绪 | 过程 | 按主题段的轨迹、转折、恢复时长 | 做 |
| 焦虑 | 担忧眉 | AU1、AU4 | 做 |
| 焦虑 | 警惕眼 | AU5，加视线偏离画面中心 | 做 |
| 焦虑 | 紧张口唇 | AU23、AU24 | 做 |
| 焦虑 | 情绪波动 | 面部极性代理的波动 | 做 |
| 焦虑 | 眨眼升高 | 眨眼率相对本人基线的 Z | 做 |
| 焦虑 | 头部微抖 | 头部角度的高频波动 | 做 |
| 反应控制 | 愤怒飙升速率 | AU4+5+7+23 的一阶差分峰值 | 做 |
| 反应控制 | 厌恶共激 | AU9/AU10 与能量、基频同步上升 | 做。不用心率，名称写声学唤醒 |
| 反应控制 | 攻击性 AU 集群 | AU4+5+7+23 共现强度 | 做 |
| 反应控制 | 面部动作加速度 | 关键点二阶差分，基座若只存角度则用头部角度二阶差分并注明 | 做，降级路径写明 |
| 反应控制 | 头部突进 | 头部前向角速度峰值 | 做 |
| 反应控制 | 嘴唇紧绷 | AU23、AU24 | 做 |
| 注意力 | 视线漂移 | 注视角速度与方向切换 | 做 |
| 注意力 | 聚焦 | 视线停留在中心附近的时长占比 | 做 |
| 注意力 | 心率减速 | 无 | 空 |
| 认知负荷 | 瞳孔直径 | 只有瞳孔位置 | 空 |
| 认知负荷 | 眨眼间隔、语速下降、停顿增多、注视回避 | 已有 | 做 |
| 掩饰-泄露 | 语义极性 vs 面部/声学方向 | 语义极性来自 DeepSeek，面部与基频来自基座 | 做 |
| 应激恢复 | 突变后回到 1σ 内的时长 | 已有标志物 | 做 |
| 话题回避 | 注视回避、头部后撤、语速降、停顿增、回答变短 | 已有 | 做。组合同时出现才升分 |
| 微表情密度 | 短于 200 毫秒的 AU 脉冲 | 取决于 OpenFace 采样 | 做。视频帧率不足时降为 `low_confidence` |

每个子项在结果里保留贡献最高的三个原始标志物（代码、Z 分数、方向）。

## 7. 突变规则（预设 v0.1.0）

写在 `config/rules-0.1.0.yaml`，扫描器只读配置。

默认值取自方案文档，作为经验起点：

- 滑动窗口：5 秒
- 偏差阈值：相对本人全片基线 2σ
- 最短持续：2 秒
- 基线最短有效时长：30 秒，不够则该标志物不报警
- 扫描对象：眨眼率、视线水平/垂直角、头部三轴、基频、短时能量、AU4、愤怒 AU 集群

关键词表初值（可在配置里改，不写死在代码里）：

- 高关注：失眠、离婚、自杀、死亡、欠债、恨、报复
- 命中后只作为「特殊内容」触发，不单独等于风险结论

预警等级预设：

| 等级 | 条件 |
|------|------|
| info | 仅关键词，标志物未超阈值 |
| watch | 仅标志物超阈值，或关键词加轻度偏离（≥2σ） |
| alert | 关键词与标志物同时触发，且偏离 ≥2.5σ 或同一主题内重复出现 |

这些数字都是预设，报告页脚打印 `rules-0.1.0`。调参只改 YAML。

## 8. DeepSeek 调用约定

三次调用，都要求 JSON 输出：

1. 主题分类：输入语句列表，输出每句的主题标签。标签只能来自 `topics-0.1.0.yaml`（健康、家庭、工作、经济、情感、法律、创伤、自我评价、其他）。
2. 语义极性：每个主题段一个极性（正 / 中 / 负）和一句依据，依据必须引用原句。
3. 特殊内容叙述：输入三层对比 JSON，输出现象、对比、趋势、预测、等级。提示词禁止编造 JSON 中不存在的心率、次数和秒数。

不上传视频、不上传原始特征全量帧。上传内容是转写文本、主题段摘要和已经算好的汇总数字。

密钥：`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` 放在本机 `.env`。

DeepSeek 失败时任务停在「叙述未完成」，分数和预警仍然可见，可单独重试叙述。

## 9. 网页页面

- 首页：上传、任务列表、状态。
- 总览：雷达、六类参考分、覆盖率、免责声明、配置版本。
- 热力图：主题段 × 标志物的 Z 分数，点击定位视频。
- 预警与特殊内容：卡片按时序排列，含视频跳转和曲线。
- 原始数据：基座指标表、转写、事件。
- 页脚始终显示：特征管道版本、指标配置版本、规则版本、DeepSeek 模型名、以及「转写文本已发送至 DeepSeek」的提示。
